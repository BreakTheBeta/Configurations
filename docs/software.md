# Software and runtime inventory

`inventory/applications.json` records every top-level app bundle found in `/Applications`, with versions and bundle IDs. `brew-leaves.txt`, `brew-versions.txt` and `brew-taps.txt` record installed packages and taps. They are reference snapshots, not executable manifests: rebuilding every old/transitive package would bring back obsolete software and broken dependencies. The Brewfiles select the usable core and an optional larger collection. Package availability was checked against Homebrew's API during the audit.

## Installation sources

- **Core Brewfile:** shell tools, Java 17, Node/nvm, uv, editors, font, Rectangle, Handy, standalone Tailscale, Codex, Bitwarden and Chrome. Alacritty is a required manual install because its cask is disabled; see the checklist.
- **Extras Brewfile:** containers, SQL, Kubernetes, compiler tools, cloud SDK, optional utilities, communications, browsers, audio/video and local AI apps. A fresh install gets available current releases, not necessarily the versions in the snapshot.
- **Personal forks:** AltTab and T3 Code Fold, with pinned source references and build instructions in `forks.md`.
- **Apple account / App Store:** Xcode, Amphetamine, GarageBand, iMovie, Keynote, Numbers and Pages. Restore prior purchases; full Xcode is required for fork builds, beyond Command Line Tools. Sign in and download platform components as needed.
- **Vendor/account installs:** Affinity Photo 2, MATLAB R2024a and its Connector, Minecraft, IntelliJ IDEA (choose the correct licence/edition), ObinsKit, Android File Transfer and MacTeX/TeX. Match purchases and actual hardware needs. ObinsKit may contain keyboard firmware settings that this filesystem audit cannot reproduce; export them in the app if needed.
- **Disabled casks:** Alacritty, qBittorrent and Sioyek were disabled for `fails_gatekeeper_check` on 2026-09-01. Install from [Alacritty releases](https://github.com/alacritty/alacritty/releases), [qBittorrent](https://www.qbittorrent.org/download) and [Sioyek releases](https://github.com/ahrm/sioyek/releases) only after checking the artifact; do not assume `brew install --cask` will work. The latter two are optional. No security checks are globally disabled by this recipe.
- **Steam library:** the user Applications folder contained Baldur's Gate 3, FTL, Factorio, Frostpunk, Golf With Your Friends, Stardew Valley, Valheim and Jackbox games (Megapicker and Party Packs 6–10). Reinstall through Steam rather than migrating the launch wrappers.
- **Hardware/system extensions:** Docker privileged helpers, Mullvad daemon, eqMac audio driver, Karabiner and optionally macFUSE need their normal installer and macOS approvals. Reconfigure eqMac audio routing/levels and MonitorControl displays for the new hardware. Wireshark was present; install its macOS vendor package and packet-capture helper if needed. macFUSE is deliberately manual because filesystem-extension approval is machine-specific.

## Runtime choices

- **Node:** Homebrew Node supports initial tooling; nvm was also installed. Existing nvm versions were 16.20.2, 18.18.0, 18.20.5, 18.20.7, 23.9.0, 24.11.0 and 24.13.1. Use **24.13.1** for the pinned T3 checkout; install older versions only for projects requiring them. Global npm packages included Claude Code 2.1.301, Corepack 0.32.0 and Yarn 1.22.21. Do not blindly install the old Node releases or overwrite package-manager shims; follow each project's packageManager declaration.
- **Go:** the old `~/.goenv` had 1.22.8 selected globally and 1.24.1 available. Extras installs goenv; after restarting the shell, use `goenv install 1.22.8` / `goenv global 1.22.8` if exact legacy behaviour is needed. Prefer project `.go-version` files. Private module configuration belongs in `~/.zshrc.local`.
- **Java/Gradle:** the active shell requested Java 17; installed user JDKs included Corretto 17.0.13, Liberica 8u382 and Azul 15.0.10. Older aliases also prepended Java 11 and Gradle 6 paths that were absent from the leaves list. Extras supplies Maven/Ant; restore old JDKs and Gradle only for projects that need them. Use project Gradle wrappers. The cleaned shell puts Java 17 first instead of reproducing conflicting PATH entries.
- **Rust:** `rustup` existed as a Homebrew formula, but the user cargo bin directory only contained uv/uvx. Install an actual toolchain using `rustup-init`; T3's release workflow used 1.95.0. Cargo caches and compiled build products are not configuration.
- **Python:** uv/uvx were standalone binaries, with optional uv tools `gunicorn` and `p2j`. Reinstall with `uv tool install gunicorn` / `uv tool install p2j` when needed. Poetry/pipx were installed too. The old seagoat/gt pipx environment was **broken** because its Python 3.11 interpreter no longer existed: use `pipx install seagoat` fresh if needed rather than copying the venv or old absolute PATH. Neovim's SQL formatting mapping also needs the `sqlformat` executable; `uv tool install sqlparse` supplies it.
- **PostgreSQL:** only `postgresql@16` was running as a Homebrew service. After restoring databases privately, start explicitly with `brew services start postgresql@16`. Redis, Podman, pure-ftpd, vsftpd and unbound were not running as Homebrew services. No service autostart is inferred from package presence.
- **Local AI:** Ollama, LM Studio and llama.cpp were installed. Download models deliberately; the Neovim `gen.nvim` config requests `dolphin-llama3:70b` on localhost:11434. It may require substantial memory/storage and a separately downloaded model. The `codeServer` alias names Qwen2.5-Coder-7B via llama.cpp. Record model availability/licensing separately; this repo contains no weights.
- **Nix and older language tools:** Nix profile/daemon, chruby/ruby-install, old Ruby source trees and .NET/Android development data existed. These are optional project-specific environments, not core shell dependencies. Reinstall through official project installers if still needed; do not copy daemon state or every historic SDK.

## Historical packages not installed automatically

The leaves snapshot additionally includes bbftp-client, bison, automake, chruby, ruby-install, ctop, gdbm, git-sizer, inetutils, ipython, libffi, libyaml, macmon, md5sha1sum, neofetch, openssl@1.1, pipes-sh, platformio, portaudio, pstree, pure-ftpd, qemu, scons, the_silver_searcher, virtualenv, vsftpd and youtube-dl. The cask inventory also included projectlibre and universal-media-server. Install only if a current project requires them and check supported replacements for discontinued software. Old taps `boz/repo`, `hashicorp/tap`, `homebrew-zathura/zathura` and `homebrew/services` are preserved in the inventory, not automatically re-added.

The audit inspected configuration files, preferences, app metadata, running app names, launch agents/daemons, package managers and local Git revisions. It did not open every GUI preference panel, inspect browser profiles, dump credential stores, read personal documents, or verify device firmware. Browser extensions/logins, purchase activation, hardware-specific display/audio settings and app-specific private state still need account sync or a private backup.
